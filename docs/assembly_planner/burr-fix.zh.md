# Burr 例子的模型与边界拼接修复

入口：`examples/assembly/paper_assemblies.py`，场景 `fig10_burr6` 和 `fig15c_burr6`。默认 `NOMINAL=True` 使用修复后的配合模型，`False` 保留原始输入。

## 两个独立原因

1. **原始 STL 没有形成一致的装配配合。** 六件网格本身封闭，但有位置偏差、槽面偏差和 3u 槽壁的局部翘曲。原始模型检测出 7 对穿插。世界坐标 `(-20, -5.59, -25) mm` 同时位于 `2L left` 和 `2u` 内部，证实这不是表面接触被误判。旧 JSON 的位姿全为零，是因为 STL 已保存装配坐标，不是丢失了变换或 mm/m 换算错误。
2. **边界拼接用了不可靠的取整去重。** 同一个交点的两次数值计算相差约 10⁻¹⁸ m，却可能落到量化网格半格的两侧。旧 `cell_regions` 把它们分成不同顶点，导致边界断开，接触质量变成 unresolved，方向随之成为 unknown。两个三角形组成的普通矩形即可独立复现此问题。

论文例子当前使用 `MeshProximity` 网格后端；这次问题不是 SDF 分辨率引起的。

## 模型修复

修复只发生在离线工具 [burr_assets.py](../../tools/assembly/burr_assets.py)，不进入通用几何预处理。

- 按列出的坐标面对齐配合槽，保留非均匀槽宽、键条侧隙和 `2L right` 的 -28.6 mm 退让面。
- 键条落座到 z=-23 mm，保留原始高度。
- 3u 翘曲面变平后出现退化三角形／T 接缝，在非均匀坐标单元上按内部占据重建封闭边界。保留槽腔，不取凸包、不填实空隙。
- 每件记录原几何摘要、目标坐标面、最大原顶点位移和 0.3 mm 修正上限。源几何超出上限时拒绝转换。

这是从现有模型推断并明确声明的**名义配合模型**，不能声称恢复了作者原始 CAD。两个 nominal manifest 已更新；原始 STL、JSON 和 raw manifest 不变。

| 零件 | 最大原顶点位移（mm） |
|---|---:|
| 3u | 0.279193 |
| 2L left | 0.070260 |
| 2L right | 0.000015 |
| 2u | 0.118916 |
| 1 | 0.072723 |
| u | 0.001949 |

## 算法修复与结果

[geometry/planar.py](../../wrs/assembly/geometry/planar.py) 先消除完全重复点，再用 KD-tree 按实际距离选择首个代表点。每个合并点与代表点的距离不超过原拓扑容差，不做传递式合并。相邻边和 T 接缝仍批量处理，没有增大 contact／near 容差。

两个完整 burr 入口都有 29 个 active、20 个 near 接触片；15 对 touching、6 对 separated，没有 interference、unknown 或 unresolved 接触片。

| 零件 | SOCP 与 Fibonacci 结果 | 方向空间维数 |
|---|---|---:|
| u、3u、2L right | feasible | 1 |
| 1 | feasible | 3 |
| 2L left、2u | blocked | 0 |

blocked 表示该件在当前状态下没有非零局部平移方向，是正常的互锁约束结果。六个装配前缀也均有明确分类。这里仍是局部方向检查，不是有限拆卸路径或整条机器人序列的证明。

本机完整名义模型的接触阶段约 1.4 s。固定同一输入，`cell_regions` 三次中位数对照：

| 输入单元数 | 修复前（ms） | 修复后（ms） |
|---:|---:|---:|
| 8 | 0.321 | 0.324 |
| 800 | 13.198 | 13.480 |
| 8,000 | 143.456 | 147.171 |

距离去重增加了少量耗时；仍使用稀疏 KD-tree 和批量投影，没有构建点数平方的距离矩阵。

## 复现与回归

从 WRS2 根目录用指定解释器运行 `-m tools.assembly.paper_assets` 可重建原生示例数据。重新启动 `paper_assemblies.py`，选择 Burr；旧进程缓存的装配和结果不会自动刷新。

2026-09-13：指定 Python 3.12 下，**192 项测试通过，82.906 s**。新增测试覆盖半格交点、2D/3D 边界、容差外间隙、原始穿插内部见证、名义网格封闭性、键条高度、修正上限，以及两个入口和所有装配前缀。
