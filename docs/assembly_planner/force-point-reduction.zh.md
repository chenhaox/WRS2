## 调用与显示

```python
from wrs.assembly import StabilityConfig, check_equilibrium

config = StabilityConfig(
    reduce_contact_points=True,       # 默认开启；False 仍清理重复点
    curved_point_budget=64,            # 每个曲面 patch 的子集点数上限
    curved_point_spacing_m=0.005,      # FPS 的位置距离尺度，5 mm
    curved_normal_angle_rad=0.17453292519943295,  # 法线距离尺度，10°
)
result = check_equilibrium(assembly, state, graph, config=config)
print(result.diagnostics['point_preparation'])
print(result.diagnostics['curved_fallback'])
```

最后两个尺度用于选点覆盖度，不是几何合并容差，也不改变接触分类。点数上限不是必须达到的数量。它限制第一次求解的曲面子集；触发完整回退时可以超过上限。

## 选点规则

| 几何 | 始终执行 | 默认开启的约简 |
| --- | --- | --- |
| 所有 patch | 对位置和法线一起去重；仅合并同法线、机器舍入尺度内落在同一空间格子的点 | 不跨 patch 或承载容量组操作 |
| 点接触 | 重复点清理后保留实际点；同位置不同法线不等价 | 不补造点 |
| 直线、同法线 | 保留原始实际点 | 保留两个端点；弯折线不会当作一条直线 |
| 平面、同法线 | 保留裁剪单元中的实际顶点 | 投影到平面，取二维凸包顶点；数值检查不通过则保留全部 |
| 曲面或变化法线 | 保留对应的位置—法线对 | 边界优先、位置和法线共同衡量的确定性最远点选取（FPS）；失败时完整回退 |

必做清理采用 `64 * float64_eps * max(0.001, max(abs(position)))` 的世界坐标尺度容差。它约为机器舍入误差量级，不用毫米级容差把相邻特征焊接起来。同格点之间的欧氏距离不超过该值；跨格的近重复点可能保留。代表点始终取输入中的真实点，不取平均。关闭约简时仍执行这些清理。

面接触的目标不是“统一保留三个点”。非退化面至少需要三个不共线点，但矩形需要四个角才能保留全部支撑边界；24 边形圆柱底面保留 24 个凸包顶点。沿多边形边均匀重采样，如果删掉角点，会缩小可承受的力矩范围。

平面凸包之所以可用：任意内部点 `p = Σ αᵢ vᵢ`，其中 `αᵢ >= 0, Σ αᵢ = 1`。把该点的力 `f` 分配为顶点上的 `αᵢ f`，合力仍是 `f`，力矩满足 `Σ vᵢ × (αᵢ f) = p × f`，总法向力也不变。相同法线和摩擦锥确保分配后的力仍然可行。这保持当前离散模型的可承载合力/力矩集合，误差限于数值运算尺度。

这要求同一个 patch 内使用同一摩擦系数、相同方向的锥，没有单个点的压力/承载上限。当前上限是每个 patch 共享的总法向力容量。以后增加局部压力上限、位置变化的摩擦或弹性模型时，需要重新审视这条约简规则。

带孔面的孔洞、接触面积和显示几何不变；只约简施力点。凸包顶点取自原始接触点，没有在孔内造点。不同 patch 保持各自的容量组，不能因为接触点重合就合并。

## 曲面覆盖与回退

FPS 使用六维特征 `[position / spacing, normal / (2 sin(angle/2))]`，同时顾及位置距离和法线方向差。实现先排序并固定并列情况的选择，完全不使用随机数。边界附近原始点和位置/法线各坐标极值优先；每次选离已选集合最远的点，然后用 NumPy 批量更新其余点的距离。达到覆盖目标或点数上限就停止。这里“边界优先”不意味着有限点数下保留所有边界顶点。

保留的是输入点及其原法线，不把曲面压平成一个平均法线的平面。子集的可行解也属于原始完整力模型；子集失败却可能仅仅是漏了关键点。因此，名义或任一扰动工况没有求得可行解时，用完整清理后的曲面点重新计算所有工况。平面的凸包约简仍保留。最终力点索引及各工况的反力都来自同一套最终模型。

`diagnostics['curved_fallback']` 表示是否回退；`reduced_attempt` 记录原子集点数和未通过的工况；`point_preparation` 记录每个 patch 的方法、点数、缓存命中与覆盖程度。如果原模型本身不可行，可能需要两次建模/求解，此时曲面子集策略可能比关闭约简更慢。

## 效率

去重使用向量化 `np.unique`；平面凸包使用 SciPy/Qhull；曲面边界映射使用 `cKDTree`，FPS 的距离更新使用数组运算，不创建 N×N 距离矩阵。FPS 时间约 O(NK)、内存约 O(N)，N 是清理后的点数，K 是选点上限。

不可变 patch 的选点结果按对象身份和策略缓存，最多保留 128 个 patch、每个至多 8 种策略，使用弱引用。新位姿/几何需要新的接触图；静力入口仍校验接触图与场景是否一致。缓存不包含受力解，因此改变载荷、质量、摩擦或容量不会沿用旧的力结果。

## floating 与 beam 显示

floating 是没有桌面的悬空堆叠。两个内部物体总质量 3 kg，重力 29.43 N；内部接触力相互抵消，单靠内部接触不能抵消总重力。底下两点是例子声明的两个辅助支撑，各最多向上 20 N，位置在下方零件底面，合力可以支撑该工况。它们不是接触检测找到的桌面接触，也不代表已规划好的机器人抓取。

辅助点现在为青色，真实接触力点仍为黄色。辅助支撑摩擦系数为 0，因此摩擦锥退化为向上的一条射线。关闭左下“floating 辅助支撑”后，底下两点消失，名义工况不可行；两物体之间的四个内部接触力点仍存在。

bridge 中选择 beam，应显示两墩上表面的 8 个点，加上载荷下表面的 4 个点，共 12 个接触力点、12 个摩擦锥。beam 的 μ=0.5，并非无摩擦接触。之前的截图同时没有力箭头，仅凭截图无法还原当时图层开关状态；当前版本已经在浏览器验证默认显示、隐藏、恢复与单体筛选，并增加明确的摩擦锥数量/隐藏提示以及“恢复受力图层”按钮。不可行工况仍保留摩擦锥，不虚构反力。

## 验证边界

装配测试 111 项、材质显示同步/回放测试 2 项通过。新增测试包括开关两种模式、点/线/弯折线、法线不连续、带孔面、多个容量组、容量限制、缓存失效/弱引用与确定性选点。

还构造了一个真实求解反例：48 个不同法线的接触点，用 8 点子集会漏掉扰动载荷唯一需要的法线。测试确认子集名义平衡通过、扰动失败，随后自动回退 48 点并通过全部工况，且所有返回的力索引对应完整模型。没有通过 mock 求解器伪造回退。

独立精确圆锥参考使用 Clarabel；约简后纯线性目标出现平坦最优集，曾返回 AlmostSolved。本次给参考问题加入严格凸的力范数代价，保留原平衡、圆锥及容量约束，不放宽状态判定；参考测试重新通过。生产求解器仍使用原 LP。

上述验证支持当前固定接触状态的静力可行性模型，不证明连续曲面的采样完备性，也不计算局部压力分布或动态稳定性。
