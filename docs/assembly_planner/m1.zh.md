## 最小 Python 调用

在 WRS2 根目录创建/运行脚本，或显式将该 checkout 加入 `sys.path`：

```python
from wrs.assembly import Part, analyze_pair, ContactConfig
from wrs.assembly.primitives import box, pose
from wrs.assembly.geometry.proximity import MeshProximity

mesh = box((0.1, 0.1, 0.1))  # metres
base, block = Part("base", mesh, fixed=True), Part("block", mesh)
backend = MeshProximity()
result = analyze_pair(base, pose(), block, pose((0.025, 0, 0.1)),
                      config=ContactConfig(), backend=backend)
area = sum(p.area_m2 for p in result.patches
           if p.classification == "active" and p.dimension == 2)
print(area)  # 0.0075
print(result.pair_diagnostics[0]["overlap"]["status"])  # touching
```

完整装配用 `analyze_contacts(assembly, assembly.initial_state(), ...)`。移除零件时从新 `AssemblyState.poses` 中移除其 ID；改变姿态必须传新 state，不读取 viewer 的隐式姿态。局部 BVH 可跨实例与 state 复用。

## 给下一任务的实际协议

| 对象 / 调用 | 关键约定 |
| --- | --- |
| `MeshData` | 顶点米制 float64，面索引整数；不可写副本；geometry ID 包含几何、方向声明和误差 |
| `PreparedMesh` | 清理后的 mesh、原面一对多 `source_face_ids`、邻接、连通组件、朝向/拓扑诊断 |
| `SurfacePatch` | `plane/general`；局部原点、法线和 `(3,2)` basis；整体残差和全部边界环 |
| `ContactPatch` | A/B 对应点、每点单位法线、维度、完整 cells/loops、权重、面积/长度、分类及来源 |
| `MeshProximity.closest_points` | 输入局部 `(N,3)` 点；只返回已完整查询的前缀，`completed_count` 与 `status` 必须读取 |
| `MeshProximity.pair_distance` | 全局无符号表面距离上下界；未完成时 upper/witness 可以为 None，不能当成无穷净空 |
| `MeshProximity.classify_overlap` | separated/touching/penetrating/unknown，独立于局部 patch，含 crossing/containment 证据 |
| `MeshProximity.prepare/index` | 有界局部缓存；默认最多各 32 项；不缓存世界姿态 |
| `ContactAnalysis` | 状态与配置摘要、patches、独立 mating、每对诊断和统计；`to_dict()` 可直接写 JSON |

平面 gap 定义为 `n_A · (p_B-p_A)`；倾斜时仿射裁剪。面积权重积分在 A 平面 chart 上；近平行但不完全平行时，交换 A/B 后投影面积可能有余弦因子差异，不是把曲面或倾斜面强行视为同一平面。

曲面 `measure_kind='near_band'`、`quality='estimated'`，gap 是**无符号表面距离区间**（provenance 明示），不能当全局 signed distance。`sampling_side='a'/'b'` 的区域分别位于对应侧原始网格；A/B 两份面积不能相加成物理接触面积。每侧保留连通组件、边界环、法线场、来源面和采样权重。

各阶段独立使用 `max_triangle_tests`：overlap、全局 surface distance、平面裁剪、曲面提取各自有限额，**不是所有阶段合计的总次数**。曲面双向提取共享其阶段预算并保留另一方向的份额；`max_cells` 限制每侧/每个曲面 patch 对的细分节点，平面限制每 patch 对的候选裁剪数。

`unresolved_area_m2` 是未知或未充分覆盖部分的保守报告量，可包含“已给出估计但边界未认证”的面积；不同 surface 对和两侧还可能重计。不能将 `estimated + excluded + unresolved` 当互斥面积分解。它也不是穿透体积或漏检概率。整体为零不证明曲面的点/线接触已恢复，需读 `lower_dimensional_contact`。

## 精度与范围

- 默认近接触带为 0.5 mm，数值零为 `1e-10 m`，平面残差为 `1e-9 m`；针对厘米至分米解析样例，不是制造精度承诺。`geometry_error_m`、`pose_error_m` 是调用者提供的空间误差界；姿态角误差需先转换成工作区域内的位移界。
- 正间隙默认只成为 near；`idealize_contact=True` 才允许平面在 `contact_tol_m` 内进入显式零间隙模型。该开关不修改 pose，不将曲面带变成 active。
- 默认只焊接完全重合顶点。主动启用 `weld_m` 时记录最大顶点位移并计入误差。退化三角形删除量有诊断；小于报告阈值的交集面积计入 unresolved。
- 平面判定必须同时通过整个平滑组件的法线偏差和最大平面残差。含倒角的组件可保守保持 general；M1 没有做 CAD 面恢复或全套解析曲面拟合。
- 实体 inside/outside 以**非自交、封闭流形**为输入前提。M1 检查开放边、非流形边、朝向不一致和嵌套 shell 歧义，**不认证所有自交或重叠面输入**。此类网格应先在输入工具中验证/修复；未来 CAD/几何后端可强化认证。
- `orientation='trusted'` 是明确的输入朝向声明，适用于开放支撑、已核验空腔 shell；它不会让开放网格凭空具有实体内部。
- 已支持对向平面覆盖的面/线/点交集；任意曲面点/线、非对向表面的边/角接触恢复尚未认证，诊断的 `unsupported_contact_features` 明示这些范围。不通过 near 带面积推导点/线承载能力。采样阴性不会宣告已排除全部几何接触。学习模型、SDF、CAD、力学和序列搜索均未加入 M1。
- 几何枚举、索引构建和法线/AABB 筛选的工作量随输入复杂度增长；预算限制精确查询和细分，不等于硬实时 CPU/内存上限。近乎重合的大型网格仍需优化，当前不宣称实时性能。
