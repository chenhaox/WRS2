# 05：静力平衡和辅助支撑

状态：待实施。前置：04。可与 06 在独立 worktree 并行。

## 目标和修改范围

建立有明确接触模式、摩擦、重力和支撑能力假设的静力基线，并输出辅助支撑需求和可审计的力分配。

负责 `stability.py`、`tests/assembly/test_stability.py`。允许复用 SciPy `linprog(method='highs')`；本阶段不迁移旧版所有实验评分函数。

## 实施步骤

1. 对 active 区域生成合法力作用点：面接触保留边界极点/内点，曲面保留法线场；孔、near 和 unknown 区域不生成力变量。
2. 每个自由零件建立三维力平衡、三维力矩平衡；内部接触对使用共同变量，A/B 受力相反，关于各自 COM 求矩。
3. 使用非负法向力和内接多面体摩擦锥；按几何尺度归一化力矩数值条件，并以物理单位回报残差。
4. 固定支撑是显式边界条件；辅助夹持作为有限能力、有限数量的支撑候选。未经机器人验证的夹持只能报告 support requirement。
5. 区分 LP infeasible、数值 unknown 和 equilibrium feasible；不要把后者命名成无条件的物理稳定。
6. 加入一组明确的外力/外力矩扰动检验。输入压力/夹持力上限可选，但若缺失必须在结果假设中标记理想接触模型。
7. 辅助支撑先枚举受限候选或贪心尝试并验证；不要声称找到最少机械手，除非确实完成对应的组合求解和证明。

## 验收

- 质量已知的箱体在水平桌面：合支持力等于重力，内部接触力成对守恒。
- 两层堆叠的自由体逐个平衡；悬空件、无支撑件失败。
- 斜面在摩擦条件变化时与解析滑动界相符，容许多面锥近似的保守误差。
- 超出支撑区域的 COM、面内孔、点/线接触不能获得虚假的抗倾覆/抗扭能力。
- 正间隙、unknown contact、未知质量或摩擦得到明确诊断。
- 改变重力方向、支撑集合、摩擦和质量后缓存失效；数值失败与物理不可行分开。
- 报告扰动集合与平衡残差，不把只测零扰动的情况宣称为鲁棒稳定。
