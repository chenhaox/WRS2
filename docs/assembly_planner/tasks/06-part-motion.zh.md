# 06：有限零件运动与拆除路径

状态：待实施。前置：03、04。可与 05 并行。

研究标注（2026-09-11）：[Assemble Them All 迁移候选](../assemble-them-all-transfer.zh.md) 的 ATA-01、02、04、06 可在本任务的路径协议和独立验证落地后评估。约束投影扩展与物理 rollout 分别命名；尚未实施，不把论文的仿真成功直接当作几何验证通过。

## 目标和修改范围

验证局部方向候选能否变成一条实际的 SE(3) 拆除路径，并给序列搜索提供带证据的动作评估器。

负责 `part_motion.py`、`tests/assembly/test_part_motion.py`。不把现有 WRS 关节空间 `RealVectorStateSpace` 当作刚体 SE(3) 规划器，也不在本任务内求机器人 IK。

## 实施步骤

1. 实现 RemovalAction / ContactPolicy 的消费和结果协议。先支持单零件固定姿态平移，保留成组刚性移动的字段与明确 unsupported 状态。
2. 使用 04 生成方向，叠加包围盒/几何特征产生的候选，搜索到明确的 outside 终态。行程根据装配和场景边界计算，不能沿用旧固定 300。
3. 对初始 active contact 允许不穿透的分离/滑动，对其他区域和障碍要求净空。预期接触只豁免指定区域、阶段和有界间隙，不给整个零件无条件碰撞豁免。
4. 调用 03 的真实几何距离/overlap，包括移动件与非接触障碍。结合距离下界和点位移上界进行自适应边验证：旋转贡献可用包围半径乘转角的保守上界。
5. 初始零间隙/切向滑动会使普通正净空距离界退化，应单独追踪允许接触约束；无法认证的区段细分并标验证级别。达到最小步长仍无可靠结论时是 unknown，不能强行通过。
6. 增加有界的 SE(3) 候选/采样搜索，使用有效旋转插值和明确 translation/rotation 尺度。螺纹/弹性卡扣/压配需要专用原语，本任务不伪造支持。
7. 返回对象位姿路径、blocked witness、最小间隙证据、采样/认证级别、预算、初末状态和 failure reason。评估过程不能永久改变输入 state。

## 验收

- 自由箱体能离开，封闭笼/挡板阻挡正确；初始无接触但稍远处有障碍也会拒绝。
- 平面滑动和分离可通过，向内运动不能因为它是 mating pair 而通过。
- 细障碍位于两个粗采样点之间时能检测或明确 unknown，不能出现 tunneling。
- 转动路径中间碰撞、完全包含、小间隙孔与凹槽使用真实几何判断。
- 预算耗尽与已验证阻挡分开；尝试有限候选失败不宣称全局无解。
- 结果具备可独立 replay 的路径、验证精度和状态摘要，复验得到一致判断。
