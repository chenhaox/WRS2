# 01：几何预处理与表面 patch

状态：待实施。前置：00 已完成并形成稳定基线。

## 目标和修改范围

从网格得到具有拓扑、方向和拟合误差信息的 `PreparedMesh` / `SurfacePatch`，以支持独立 contact surface 分析。

负责 `geometry/preprocess.py`、`geometry/surfaces.py`、`geometry/planar.py` 中的坐标投影/边界基础及 `tests/assembly/test_surfaces.py`。裁剪算法由 02 负责；公共辅助符号在交接时固定，避免 02/03 重复实现。

## 实施步骤

1. 读取 `wrs/geom/surface.py`、`geometry.py`、`ops2d.py`，复用合适的邻接思路，但把分析精度、焊接公差和原 face ID 映射独立管理。
2. 检测退化/重复三角形、开放边、非流形边和朝向不一致。可配置焊接与定向；不可确定外法线的情况给出诊断，禁止根据全局质心简单翻转凹件/空腔的每个面。
3. 建立面邻接和连通组件。平面生长同时检查局部法线、seed/整体拟合平面的最大残差及区域内法线偏差；排序和 seed 固定，避免随机或输入遍历造成不可解释差异。
4. 提取所有外环、内环、孤立组件及其方向。对于孔和复杂连通关系保留实际三角形覆盖作为真源，边界异常不得退化为凸包。
5. 输出稳定 patch ID、面积、局部坐标系、法线可靠性、拟合残差及 source face IDs。不能通过重排面片破坏追溯。
6. 曲面先标 general，不要求本任务拟合全部解析曲面。输出足够的邻接和法线信息供 03 使用。

## 验收

- 合法立方体得到六个平面 patch；改变其空间朝向后仍正确。
- 含内孔平面得到外环和内环；同向但不连通的区域保留为独立组件。
- 缓慢弯曲的三角带不能因相邻法线变化小而变成一整个平面。
- 三角顺序变化与细分不应显著改变几何结果，source ID 映射可验证。
- 开放/非流形/反法线/退化 mesh 有明确诊断；清理前后面积变化有记录。
- 焊接阈值边界 fixture 确认不会把窄槽或两片独立薄壁合并。
