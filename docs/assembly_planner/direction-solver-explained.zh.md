## 六次 LP 是六个问题，不是只试六个固定方向

把 d=(d_x,d_y,d_z) 想成一根表示移动意图的箭头。接触约束规定哪些箭头允许，LP 每次问一个问题：在遵守全部限制的前提下，能否尽量朝右、左、前、后、上、下？

例如零件被限制在一根斜轨道上：d_x=d_y、d_z=0。直接试 +x 箭头会违反约束。LP 最大化 d_x 时可以同时调整 d_y，得到 (1,1,0)，最后归一化成 (0.7071,0.7071,0)。所以它能找到斜轨道方向。

坐标限制 −1≤d_j≤1 只是让数学问题有有限答案，**不是移动 1 米的指令**。这里求的是方向，随后统一箭头长度。−d_x 最大就是尽量朝 −x；其他坐标同理。

为什么六次足够检查非零解是否存在？任何非零箭头至少有一个坐标为正或为负，对应问题的最优值就会大于零。如果六个最优值都为零，就只剩零向量。该结论针对给定有限约束的精确数学问题；实际求解仍检查容差、求解器状态和几何诊断。

这六个问题主要判断能否移动，并提供代表候选。它们没有优化装配行程、姿态误差、抓取或整条路径。

## 为什么还要补方向

LP 可能给出偏在允许区域边缘的解。增加候选是为了给后续路径验证更多选择：

| 种子 | 直观意义 |
| --- | --- |
| 零空间 | 同时沿所有当前接触面滑动而不立即分开的方向。例如轴孔轴线。并非所有可行动作都在零空间内。 |
| 单个接触的切向 | 沿某一个接触面擦着走；是否违反其他面，还需检查。 |
| 两法线叉积 | 同时沿两接触的切向运动，常对应两约束边界的交线。 |
| 64 个固定随机种子 | 在其他位置撒一些候选，增加覆盖多样性；无法保证恰好命中轴孔这种孤立方向。 |

种子一开始可以不合法。归一化使 (1,1,0) 和 (10,10,0) 表示同一方向；去重避免重复验证。最后统一检查。

批量验证就是制作一张“方向 × 接触限制”的表：每项是法线与方向的点积。有一项明显小于零，就拒绝该候选。`matrix @ batch.T` 一次计算整批表格，代替 Python 逐点相乘。当前每批最多 128 个候选；表格之后还要构造每个候选的诊断记录。

### 随机性与只返回一个方向

当前 `ConstraintConfig.seed=0`，每次调用都新建使用同一 seed 的随机数生成器，因此同样输入和环境下结果可复现。2026-09-11 用指定 Python 解释器对单平面和对向平面案例分别重复调用两次，完整序列化结果相同；关闭随机种子后，候选数分别从 49 降到 9、从 7 保持为 7，均仍返回局部可行候选。这不是所有几何或有限路径覆盖的证明。

`ConstraintConfig(random_samples=0)` 已能关闭随机补充，但当前函数仍返回未排序候选，尚未实现“最优方向”。随机补充可以用于探索，不适合作为局部最优方向的定义；仅从有限候选中挑选余量最大者也不等于连续允许域上的全局最优解。

建议后续平移接口默认返回一个确定的局部首选方向：先识别允许空间的维数，再求该空间内的最大方向余量；若有多个同等最优解，优先符合指定装配/接近方向，否则在明确的零件坐标系内使用固定规则打破平局。无约束时也使用任务偏好或固定规则。轴孔只剩正负轴向时，两者都应通过原约束复核，再按该规则选一个。退化模型在三维中的角度容忍仍为零，不能把子空间内的指标当作三维容错。

首选方向接口可以只给一个结果，但应保留允许域/约束，让后续路径验证失败时能请求其他确定性候选。例如轴向正负两方向局部等价，远处遮挡可能只允许其中一个。随机探索可另设可选策略并显式记录 seed。上述默认策略与最优方向接口仍为设计建议，未改动生产求解器。

## 最大方向误差公式为什么成立

以下是拟采用的目标，不是现有 LP 的目标。设 n_i 和 d 都是单位向量。

一个限制的边界是 n_iᵀd=0。在方向空间中，点 d 到这个过原点平面的距离为 |n_iᵀd|；对合法方向去掉绝对值即可。单位球上到对应大圆的角距离 α_i 则满足 n_iᵀd=sin(α_i)。所以点积大，表示离这条禁止边界远。这里是**方向空间的无量纲距离/角度**，不是零件之间的毫米间隙。

令 t 表示所有边界余量中最小的那个：

\[
\max_{d,t} t \quad\text{subject to}\quad n_i^T d\geq t\ (\forall i),\quad \|d\|_2\leq1.
\]

`subject to` 只表示“必须遵守这些条件”。它本身不会把方向推向中间。n_iᵀd≥t 使 t 不能超过任何一条边界的余量；外面的 max t 再把这条最短余量推到最大。两部分一起才得到离最近边界最远的方向。

二维例子：允许向右、向上，d=(cosθ,sinθ)，0°≤θ≤90°。两条余量是 cosθ 和 sinθ：

| θ | 最短余量 t | 可容许的最坏方向偏转角 |
| --- | ---: | ---: |
| 10° | 0.173648 | 10° |
| 20° | 0.342020 | 20° |
| 45° | 0.707107 | 45° |
| 80° | 0.173648 | 10° |

45° 到两侧一样远，因此是这个目标的最优解。长度上限防止靠无限放大 d 虚增点积。只要最优 t>0，缩短的 d 都还能被放大来提高 t，所以最优解自动在单位球面上。t=0 时不能这样推断，也不能归一化零向量。

这是标准 SOCP 形式；可参考 [CVXPY 的二阶锥规划说明](https://www.cvxpy.org/examples/basic/socp.html)。用此目标评价局部方向是本项目的设计建议，不等于文献已经证明真实装配成功率最高。

## 轴孔等低维情况如何处理：待实施算法

先检查是否存在非零解，然后识别“对所有可行运动都必然等于零”的限制，最后降到剩余自由度求解。不要把全部 N 直接求零空间作为允许集合，否则连单平面上的向上分离都被丢掉。

一种适合做正确性基准的识别方法：对每个约束行 i，在原可行锥与单位盒的交集内求 max n_iᵀd。如果可认证的上界为零，这一行对所有可行 d 都只能等于零，记入等式矩阵 E。仅看到某个可行解的目标值接近零不够；要检查求解状态、上界/对偶证据及数值误差。几何法线自身不确定时，不能强行声称准确退化。

取 E 的零空间正交基 B，让 d=Bu。剩余不等式变成 NB u≥0。只丢掉经过验证在该子空间中为零的行，对非零投影法线重新归一化。

| 剩余维数 k | 处理 |
| --- | --- |
| 0 | 没有非零局部方向。 |
| 1 | 测试轴线正负两个单位方向，分别保留满足所有原约束的结果；孔底可能只留一个。 |
| 2 | 在允许平面内研究单位圆上的圆弧；有边界时求弧内余量，无剩余限制时按接近侧或其他任务条件选方向。 |
| 3 | 使用三维球面最大余量目标；没有任何约束时按任务偏好产生候选。 |

例如轴孔的 d_x=d_y=0，B 就是 z 轴；换成斜轴，B 自动随轴方向旋转。即使没有直接相反的法线对，多个法线也可能共同封住一个平面，所以不能只查相反法线对。

最后还要检查完整路径：两个轴向都存在，不代表两边都能拆出。子空间内的方向余量与偏离该子空间的角度容忍必须分开报告；理想零间隙轴孔对径向偏转的容忍为零。正间隙轴孔则保持 near 间隙模型，不人为添加零间隙等式。

上述降维策略用单平面、对向平面、轴孔、盲孔、斜轴、三条 120° 径向法线及六向封闭的解析约束核对过维数，尚未实现为 WRS2 API。逐行 LP 可以作为可靠基准，之后再做冗余压缩和缓存；数值上“很窄”和“精确低维”的区分应有诊断和容差敏感性测试。
