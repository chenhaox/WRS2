# `wrs.assembly`

Prefer these in-house utilities over trimesh / scipy / open3d / fcl. Auto-generated by `tools/gen_api_index.py` (static ast scan); re-run after adding functions.

## `wrs.assembly.constraints`
_Vectorized one-sided contact constraints and local translation/twist candidates._

- `rebase_twist(twist_world, old_reference_m, new_reference_m)` — Change reference while preserving the same rigid velocity field (world).
- `contact_constraints(graph, moving_part_ids, *, reference_world_m=None, config=None)` — Construct constraints across a rigid moving-group/stationary-group cut.
- `candidate_motions(graph, moving_part_ids, *, config=None, reference_world_m=None)` — Generate nonzero translation or normalized six-dimensional directions.
- **class `ConstraintConfig`** — Local candidate controls; these do not define a finite motion validator.
- **class `LocalConstraints`** — Rows satisfy A@[v,omega] >= 0; world metres and an explicit reference.
  - methods: `residuals`
- **class `MotionCandidates`** — Local directions and evidence; every finite path still needs validation.

## `wrs.assembly.directions`
_Deterministic translation directions on a sphere or a certified subspace._

- `fibonacci_directions(sample_count=6500)` — Immutable, repeatable (K,3) unit directions; midpoint z, golden angle.
- `solve_directions(normals, *, config=None)` — Compute local pure-translation directions from outward constraint rows.
- `assembly_directions(graph, moving_part_ids, *, config=None, constraint_config=None)` — ContactGraph adapter; preserve uncertain contact evidence in the result.
- **class `DirectionConfig`**
- **class `DirectionResult`**

## `wrs.assembly.io`
_Versioned JSON manifests and raw STL import; no pickle/eval or unit guessing._

- `unit_scale(length_unit)` — Return metres per explicitly declared input unit.
- `read_mesh(path, *, length_unit, orientation='auto', geometry_error_m=0.0)` — Read STL into local float64 metres, preserving raw triangle provenance.
- `load_assembly(manifest_path, *, length_unit=None)` — Read a wrs.assembly/1 JSON manifest relative to its own directory.
- `save_assembly(assembly, path)` — Write a self-contained metre manifest with inline analysis geometry.
- `save_report(report, path)` — Serialize evidence as UTF-8 JSON. NaN/infinity are rejected.

## `wrs.assembly.model`
_Immutable M1 models: metres, radians, kilograms and world-frame witnesses._

- `readonly(value, dtype=np.float64, shape=None)` — Copy an array onto immutable storage, validating shape and finiteness.
- `checked_tf(value)` — Validate a right-handed local-to-world rigid transform, shape (4,4).
- `freeze(value)` — Recursively copy metadata, protecting shared caches from mutation.
- `to_dict(value)` — Convert models and immutable arrays/mappings to JSON-compatible values.
- `digest(value)` — Stable digest including configuration and coordinate frame.
- **class `MeshData`** — Local (N,3) vertices in metres and (F,3) indices.
- **class `Part`** — A distinct instance; assembled_tf maps local metres into world metres.
- **class `MatingRelation`** — Design relation, independent of load-bearing contacts.
- **class `Assembly`** — Instances with explicit physical and design metadata.
  - methods: `initial_state`
- **class `AssemblyState`** — Explicit poses; missing instances are absent, not implicitly at rest.
  - methods: `present_part_ids`
- **class `GeometryConfig`** — Independent preprocessing tolerances (length m, area m², angles rad).
- **class `ContactConfig`** — Separate numerical, zero-gap-model, near-band and query tolerances.
- **class `PreparedMesh`**
- **class `SurfacePatch`**
- **class `Region`** — Non-overlapping cells and oriented loops including holes, in world m.
- **class `ContactPatch`**
- **class `ContactAnalysis`**
  - methods: `to_dict`

## `wrs.assembly.primitives`
_Deterministic metre-scale meshes for examples and analytical regression._

- `pose(translation=(0, 0, 0), rotation=None)` — Construct a local-to-world rigid pose, translation in metres.
- `box(size=(0.1, 0.1, 0.1))` — Centered solid box with outward winding; side lengths in metres.
- `rectangle(size=(0.1, 0.1), *, upward=True, alternate_diagonal=False)` — A finite open support in z=0 with explicitly trusted winding.
- `rectangular_ring(outer=0.1, inner=0.04, *, upward=True)` — Square planar ring, analytic area outer²-inner², with a real hole.
- `cylinder(radius=0.02, height=0.08, sections=48, *, inner_radius=0.0)` — Closed Z-axis cylinder or annular tube, centered at the origin.
- `sphere(radius=0.025, sections=24, rings=12)` — Closed latitude mesh; exact poles allow point-contact fixtures.
- `combine(meshes)` — Combine disjoint meshes into one, preserving winding and components.

## `wrs.assembly.stability`
_Static equilibrium with paired forces and an inscribed friction pyramid._

- `check_equilibrium(assembly, state, graph, *, config=None, external_wrenches=(), supports=())` — Balance every free body under gravity and declared loads.
- `find_support_requirements(assembly, state, graph, candidates, *, config=None, external_wrenches=(), max_supports=2, max_subsets=64)` — Bounded enumeration; solutions are support requirements, not robot plans.
- **class `ExternalWrench`** — World force (N) and world torque about this body's COM (N m).
- **class `LoadCase`** — An additional simultaneous set of loads, added to gravity/base loads.
- **class `SupportCandidate`** — A finite unilateral force at a declared point, not a validated grasp.
- **class `StabilityConfig`**
- **class `EquilibriumCase`**
- **class `EquilibriumResult`**
- **class `SupportSearchResult`**

## `wrs.assembly.geometry.mesh_bvh`
_CPU triangle BVH and exact primitive witnesses in double precision._

- `aabb_distance(lo_a, hi_a, lo_b, hi_b)` — Euclidean lower bound between axis-aligned boxes.
- `closest_on_triangle(point, triangle)` — Closest point, including face interior, edges and degenerate triangles.
- `segment_pair(p, q, r, s)` — Closest points on two closed segments, including parallel/zero-length.
- `triangle_pair(a, b, tol=1e-10)` — Minimum-distance witnesses and a strict transverse-intersection flag.
- `node_pairs(a, b, max_distance=np.inf)` — Yield leaf pairs in increasing box-bound order, without an F×F array.
- **class `BudgetExceeded`**
- **class `QueryBudget`** — Shared upper bound on primitive triangle tests within a query.
  - methods: `consume`
- **class `MeshBVH`** — Median-split local mesh BVH; placement leaves the cached mesh untouched.
  - methods: `placed`
- **class `PlacedBVH`**
  - methods: `closest`

## `wrs.assembly.geometry.planar`
_Plane charts and convex cell clipping; holes are represented by cell unions._

- `plane_basis(normal)` — Return a (3,2) right-handed orthonormal plane basis, u cross v = n.
- `clean_polygon(poly, tol)` — Remove adjacent coincident vertices without filling concavities.
- `polygon_measure(poly)` — Return signed area (m²) and centroid (m), including degenerate cells.
- `clip_halfplane(poly, normal, offset, tol)` — Clip a convex cell to dot(p, normal)+offset >= 0 (chart metres).
- `convex_intersection(a, b, tol)` — Intersect two convex polygons, retaining line and point intersections.
- `trace_edges(edges)` — Trace oriented index edges into every closed ring; report bad topology.
- `cell_regions(cells, tol)` — Group oriented 2D/3D cells and recover holes, splitting T junctions.
